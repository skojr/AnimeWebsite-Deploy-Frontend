# *Anime Discovery & Social Hub Frontend*
Created by: **Samuel Obeng**

## Features
- View trending anime
- Create and read community posts
- Chat with a bot for anime suggestions
- User sign up and login

## Tech Stack
- React.js
- React Router
- Axios for API requests
- CSS Modules
- JWT for authentication
